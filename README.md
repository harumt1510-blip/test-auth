# test-auth — Python認証アプリ

ユーザー登録 → ログイン → 会員ページ → ログアウトを試すための、日本語のローカル練習用アプリです。Python 3.10以上で動き、追加パッケージは不要です。GitHubに置くだけでは起動しません。ダウンロードして自分のパソコンで動かします。

## 起動する

1. このページの **Code → Download ZIP** を押し、ZIPを展開します。
2. 展開した `app.py` のあるフォルダーでターミナルを開きます。
3. 次のコマンドを実行します。

Windows:
```powershell
py -3 app.py
```
Linux:
```bash
python3 app.py
```

4. ブラウザで **http://127.0.0.1:8000** を開きます。
5. 「新しく登録する」でユーザー名（半角英数字・アンダーバー3〜32文字）と、練習専用のパスワード（12〜256文字）を登録します。登録すると会員ページが開きます。
6. ログアウトして、登録した情報で再ログインできます。

終了はターミナルで **Ctrl+C**。ユーザー情報は `data/auth.sqlite3` に残るので、再起動後もログインできます。最初からやり直す場合は、アプリを終了して `data` フォルダーを削除してください。登録した全ユーザーと全セッションが消えます。

## 認証の構成と流れ

| 構成 | 役割 |
|---|---|
| `app.py` / `Handler` | HTML画面、登録・ログイン・ログアウト処理 |
| `AuthServer` / SQLite | ユーザー、セッション、操作回数を保存 |
| `password_hash()` | ユーザーごとのランダムsaltとscryptでパスワードをハッシュ化 |
| `session()` / `new_session()` | Cookieのトークン照合、期限確認、ログイン時の交換 |
| `test_auth.py` | 実際のHTTPリクエストで認証と拒否動作を検証 |

ブラウザが `/login` を開くと、匿名セッションとCSRFトークンを作成します。フォームから `POST /login` が届くと、CSRFトークンを確認し、SQLiteのユーザーを検索してパスワードハッシュを照合します。成功時は以前のセッションを削除し、新しいランダムトークンをCookieで発行して `/account` に移動します。会員ページへの各リクエストで、トークンと30分の有効期限を照合します。`POST /logout` はセッションをサーバー側で削除し、Cookieも消します。

## 資格情報とトークンの扱い

- パスワードの平文は保存しません。scryptのハッシュとユーザーごとの16バイトsaltを保存します。SQLはパラメーター指定で実行します。
- セッションは32バイトの暗号学的乱数から作成します。ブラウザにはトークン、DBにはそのSHA-256ハッシュを保存します。JWTや外部サービスのAPIキーは使いません。
- Cookieは `HttpOnly`、`SameSite=Strict`、有効期限30分。期限はログインから固定で、操作しても延長しません。ログイン時にトークンを交換して以前のトークンを無効にします。
- 登録・ログイン・ログアウトの全POSTでCSRFトークンを確認します。ログアウトをGETで実行できません。
- 登録・ログインはクライアントIPごとに1分間10回まで。存在しないユーザーでもパスワードハッシュ計算を行い、ログイン失敗の表示を共通化します。
- ページはキャッシュ禁止。HTMLのユーザー名はエスケープし、画面埋め込みも禁止します。リクエストや秘密情報はログ出力しません。
- DBは `.gitignore` の対象です。実際のユーザー情報、Cookie、パスワードをGitHubへアップロードしないでください。

## 使用範囲

自分のPCだけで試す練習用です。`127.0.0.1` のみで待ち受けます。HTTPのローカル利用のためCookieの `Secure` 属性は付けていません。インターネットには公開しないでください。本番運用にはHTTPS、Secure Cookie、運用向けサーバー、永続的な監査、アカウント回復など別途設計が必要です。GitHubやChatGPTのパスワードは登録せず、練習専用のものを使ってください。

## 動作確認

```bash
python3 -m unittest -v
```

Windowsでは `py -3 -m unittest -v`。一時DBと空きポートで動き、実際の登録情報には触れません。
